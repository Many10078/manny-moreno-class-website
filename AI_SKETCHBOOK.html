Reflection

For this exercise, I used AI to help me experiment with JavaScript and create an interactive way to show my design process. I asked AI to help me turn my original sketch-to-finished-piece interaction into a larger gallery where users could compare multiple projects using a slider. My first version was much simpler, so I had to revise the idea and troubleshoot the code as I expanded it.

The final result allows me to move through twelve different projects while comparing the sketch with the finished work. I understand the basic structure of the JavaScript, including how the slider changes the image position and how the buttons change which project is displayed. I could modify smaller parts of the code myself, although I would probably use AI again if I wanted to create a more complicated interaction.
